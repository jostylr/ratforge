## Introduction

### What is RatForge?

RatForge is a web-based mathematics learning platform designed to help learners master arithmetic skills progressively—from basic counting through operations with whole numbers, fractions, decimals, and beyond. The platform emphasizes:

- **Progressive Mastery**: Build skills incrementally, with each concept reinforcing the previous
- **Visual & Interactive Learning**: Engage with manipulatives like dragging kittens into baskets
- **Event-Sourced Progress**: Every action is tracked, enabling detailed progress analysis
- **Personalized Learning**: Bookmarkable URLs allow easy return to personal dashboards
- **No Registration Friction**: Start learning immediately without email/password

### Core Philosophy

RatForge is built on the principle that **understanding comes before memorization**. Rather than drilling facts in isolation, exercises are designed to build conceptual understanding through:

- Visual representations (arrays, number lines, fraction bars)
- Concrete-to-abstract progression
- Multiple representations of the same concept
- Immediate, constructive feedback

## Getting Started

### For New Users

1. Visit the RatForge homepage
2. Click **"Start Learning"** to create your personal learning space
3. **Bookmark your unique URL** (e.g., `/u/abc123xyz`) to return later
4. Explore the dashboard and choose a topic or exercise

- **Dashboard**: Your home base showing progress and quick links

- **Practice Page**: Browse all available exercises
- **Individual Exercises**: Interactive learning activities

## For Learners

### Beginner (Ages 4-6)

**Where to Start:**
- 🔢 **Counting - Number Recognition**: Learn to identify numbers 1-20
- 🐱 **Counting - Kittens in a Basket**: Fun drag-and-drop counting practice
- 👀 **Counting - Subitize**: Train your brain to recognize quantities instantly

**Tips:**
- Take your time—there's no timer pressure
- Click the "Try Again" button if you make a mistake
- Celebrate small wins! Each correct answer builds confidence
- Ask a parent or teacher if instructions are unclear

**Skills You'll Build:**
- One-to-one correspondence (each object gets counted once)
- Number recognition (seeing "5" and knowing what it means)
- Quantity comparison (which group has more?)

**Where to Start:**
- ➕ **Basic Operations - Add Within 10**: Master fundamental addition

- ✖️ **Multiplication - Arrays**: See multiplication as rows and columns

**Tips:**
- Use the visual aids provided—they're there to help!
- Practice "fact families" to see how addition/subtraction connect

**Skills You'll Build:**
- Addition/subtraction fact fluency

## For Parents

### Supporting Your Child

**Do:**
- ✅ Sit with your child during initial sessions
- ✅ Celebrate effort, not just correct answers
- ✅ Ask "How did you figure that out?" to encourage explanation
- ✅ Use the bookmark feature so your child can return independently
- ✅ Connect exercises to everyday life ("Let's count the apples!")

**Avoid:**
- ❌ Taking over when your child struggles (let them work through it)
- ❌ Focusing only on speed or correct answers
- ❌ Comparing to siblings or classmates
- ❌ Using math as punishment ("Do math problems until you behave")

### Progress Monitoring

The dashboard shows:
- **Total Attempts**: Overall engagement level
- **Correct Answers**: Success rate
- **Accuracy Percentage**: Consistency measure
- **Completed Exercises**: Mastery indicators

### Creating a Learning Routine

**Suggested Schedule:**
- **Daily**: 10-15 minutes of focused practice
- **Weekly**: Try 1-2 new exercise types
- **Monthly**: Review progress and celebrate achievements

### When to Seek Additional Help

Consider extra support if your child:
- Consistently struggles with age-appropriate exercises after multiple attempts
- Shows frustration or anxiety around math
- Has significant gaps in foundational concepts
- Needs challenges beyond available exercises

## For Teachers

### Classroom Integration

**Warm-Up Activities (5-10 minutes):**
- Project subitizing exercises on the board
- Class-wide number bond challenges
- Quick mental math with estimation exercises

**Station Rotation:**
- Set up RatForge as one learning station
- Students work independently while you guide other groups
- Rotate every 10-15 minutes

**Homework Assignments:**
- Assign specific exercise categories
- Use worksheet generation for printable practice
- Students bookmark their URLs to track progress

### Differentiated Instruction

| Learner Level | Recommended Exercises |
|---------------|----------------------|
| Below Grade | Previous grade-level counting, basic facts |
| On Grade | Current curriculum-aligned exercises |
| Above Grade | Challenge with next-level or multi-step problems |
| Struggling | Subitizing, visual representations, manipulatives |
| Advanced | Algebra, multi-step word problems |

### Assessment Strategies

**Formative Assessment:**
- Observe students during practice sessions
- Check dashboard stats for individual progress
- Use incorrect answers to identify misconceptions

**Diagnostic Assessment:**
- Have students explain their strategies
- Note which visual representations they prefer
- Identify specific skill gaps from exercise patterns

**Summative Assessment:**
- Assign comprehensive exercise sets
- Use worksheets as paper assessments
- Compare progress over time via dashboard metrics

### Common Misconceptions to Watch For

| Topic | Common Misconception | Remediation |
|-------|---------------------|-------------|
| Counting | Skipping numbers or double-counting | Use "Count and Move" exercises |
| Addition | Always starting from 1 instead of counting on | Practice "counting on" strategy |
| Subtraction | Thinking subtraction is commutative | Use visual bar models |
| Fractions | Larger denominator = larger fraction | Compare using visual fraction bars |
| Decimals | Treating decimals like whole numbers (0.15 > 0.9) | Emphasize place value |

### Worksheet Generation

Many exercises support worksheet generation for offline practice:
- Navigate to `/worksheet/{exercise-id}` (e.g., `/worksheet/counting-subitize`)
- Print for homework or assessments
- Include answer keys for self-checking

## Exercise Categories

### Counting & Numbers 🔢
Foundation of all arithmetic. Includes recognition, comparison, ordering, and special number systems like Roman numerals.

**Exercises:** Subitize, Recognize, Objects, Compare, Odd/Even, Greater/Less, Ordering, Number Names, Ordinal Numbers, Roman Numerals, Kittens in Basket

### Basic Operations ➕➖
Addition and subtraction within 20, building toward fluency.

**Exercises:** Add Within 10, Subtract Within 10, Number Bonds, Doubles, Word Problems, Fact Families, Tens and Ones, Mental Math, Estimation

### Regrouping 🧮
The key skill for multi-digit arithmetic, using left-to-right (abacus-style) methods.

**Exercises:** Complements of 10, Left-to-Right Addition, Left-to-Right Subtraction

### Multiplication ✖️
From arrays to algorithms, building multiplication understanding.

**Exercises:** Arrays, Times Tables, Box Method, Word Problems, Properties, Square Numbers, Lattice Method, Multiples

### Division ➗
Fair sharing, remainders, and long division.

**Exercises:** Fair Sharing, Division Facts, Remainders, Word Problems, Long Division, Divisibility Rules, Prime Numbers, Factors

### Fractions ½
From parts-of-whole to operations with unlike denominators.

**Exercises:** Parts of Whole, Compare, Equivalent, Add/Subtract (same & different denominators), Mixed Numbers, Number Line, Simplify, Multiply, Divide, Fraction of Number, Ratios

### Decimals 0.5
Place value, operations, and connections to fractions and percentages.

**Exercises:** Tenths, Place Value, Add, Compare, Subtract, Multiply, Decimal to Fraction, Percentages

### Geometry 📐
Shapes, measurement, and spatial reasoning.

**Exercises:** Identify Shapes, Perimeter, Area, Symmetry, Angles, 3D Shapes, Coordinate Plane, Volume

### Data & Probability 📊🎲
Reading graphs, analyzing data, and understanding chance.

**Exercises:** Bar Graphs, Pictographs, Tally Charts, Mean/Median/Range, Line Graphs, Coin Flip, Spinner

### Time & Money 🕐💵
Practical life skills with telling time and handling money.

**Exercises:** Hour & Half Hour, Elapsed Time, Quarter Hours, Time Word Problems, Counting Money, Making Change, Money Word Problems

### Measurement 📏
Length, weight, capacity, and temperature.

**Exercises:** Length, Weight, Capacity, Temperature, Time Conversion

### Patterns & Algebra 🔢🧮
Skip counting, pattern recognition, and early algebraic thinking.

**Exercises:** Skip Counting, Shape Patterns, Number Patterns, Missing Number, Solve for X, Order of Operations, Input/Output Tables, Evaluate Expressions

### Place Value
Understanding our number system's structure.

**Exercises:** Expanded Form, Rounding, Compare Numbers, Standard Form

## Learning Pathways

### Pathway 1: Early Elementary (K-2)
```
Counting Recognition → Object Counting → Compare Quantities
    ↓
Kittens in Basket → Subitize → Odd/Even
    ↓
Add Within 10 → Subtract Within 10 → Number Bonds
    ↓
Doubles → Tens and Ones → Word Problems
```

### Pathway 2: Elementary (3-4)
```
Basic Facts Review → Fact Families → Mental Math
    ↓
Regrouping Complements → LTR Addition → LTR Subtraction
    ↓
Arrays → Times Tables → Multiplication Properties
    ↓
Fair Sharing → Division Facts → Remainders
    ↓
Parts of Whole → Compare Fractions → Equivalent Fractions
```

### Pathway 3: Upper Elementary (5-6)
```
Multi-digit Operations → Box Method → Lattice Method
    ↓
Long Division → Divisibility → Prime Numbers
    ↓
Fraction Operations → Mixed Numbers → Simplify
    ↓
Decimals → Percentages → Decimal-Fraction Conversion
    ↓
Algebraic Thinking → Order of Operations → Solve Equations
```

### Pathway 4: Remediation Track
```
Subitize (build number sense) → Count Objects (one-to-one)
    ↓
Number Recognition → Greater/Less → Ordering
    ↓
Add Within 10 (with visuals) → Subtract Within 10 (with visuals)
    ↓
Number Bonds → Fact Families → Mental Math Strategies
```

### Adding New Exercises

1. Create a new file in `src/exercises/{topic}/{name}.ts`
2. Implement the `Exercise` interface:
   ```typescript
   export const myExercise: Exercise = {
     id: "topic-name",
     topic: "topic",
     title: "Display Title",
     description: "Short description",
     difficulty: 1, // 1-5
     generate(seed?) { /* return ExerciseInstance */ },
     validate(instance, answer) { /* return ValidationResult */ },
     renderHTML(instance) { /* return HTML string */ },
   };
   ```
3. Register in `src/exercises/index.ts`
4. Add to practice page in `src/templates/pages/practice.ts`

## Appendix: Glossary

| Term | Definition |
|------|------------|
| **Event Sourcing** | Architecture pattern where state is derived from a sequence of events |
| **Exercise Instance** | A specific generated problem with parameters and correct answer |
| **Materialized View** | Computed data derived from events for quick access |
| **Passwordless Auth** | Authentication via unique URL token instead of password |
| **Seed** | Number used to generate reproducible random exercises |
| **Subitizing** | Instantly recognizing quantity without counting |
| **Token** | Unique identifier for user session/access |
